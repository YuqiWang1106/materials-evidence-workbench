为已经列出的 entities 写出属性段；引用实体时只用给定的 local_id。
entities 中 known 为 true 的是前文已经列出的实体（如前面章节定义的配方或合成）；本窗口中属于它们的结果、表征和讨论，挂在它们的 local_id 上。

每段属性是一条可以对照原文核对的事实，按下面的方式写：
1. cite 列出证明这段属性的片段 id（只写编号本身），按原文顺序；不要抄写原文，程序按编号取出原文。一句话、文本中的一行、表格的一个单元格各是一个片段。
2. 所引片段包含 text 中的每一个数值和单位。一段属性只引能证明它的少数几个片段；内容分散时拆成几段属性，每段各引自己的片段。
   不得从未引用的片段、另一份样品或窗口外借用数值；只引用不含数字的概括句不能支持额外数值。
3. text 用原文的写法简洁复述所引片段证明的内容；提到其他实体时写它在文中的名称。
4. 原文有哪类内容就写哪一段；原文没有的段落就留空。

配方（formulation）按内容分到这些段：
- 「原料」：每个组分写一段，text 是「材料名 用量 单位」，refs 含该材料；配比、总添加量也写在这里。
  · 组成表的每一行（一个组分及其用量）写成一段；cite 这一行的行名格和数值格。
  · 表格按样品分列时，每个样品只写自己那一列的数值，cite 这一行的行名单元格和该样品那一格；「—」或空白表示未加入，跳过；一行中有空格或个别格读得不齐时，其余有数值的格照常写。
  · 一个样品的组成跨几个块或几张图（表的上半部和下半部）时，每一部分的组分都写上。
  · 权利要求组合物：范围写一段，优选范围另写一段。
- 「制备过程」：制备步骤，以及温度、时间、转速等条件。
- 「性能」：测得的结果，每个测得值写一段：性能名、数值和单位，以及定性结果和对照基线；所用标准或条件写在 text 末尾的括号里。refs 含该性能。
- 「测试方法」：怎样测——标准、试样尺寸、仪器条件、测试步骤，不含测得值。
- 「结论」：作者对结果的判断和评价，以及从对照数据读出的趋势；text 中写明依据哪些数据。
- 「解释」：作者给出的原因和机理（归因于致密炭层；磷系与氮系协同提高阻燃效率）。
- 一句话里既有测得值又有判断或原因时，测得值写「性能」，判断写「结论」，原因写「解释」，各配引文。
- 几个配方之间的比较或趋势，在每一个被比较的配方上各写一段，text 中写明比较的是哪些配方，refs 列出其他被比较的配方。
- 一类样品的结论，写在属于这一类的每个具体样品上。
- 一次合成：原料和用量写「原料」，步骤写「制备过程」，对产物测得的产率、结构表征、聚合度、溶解度写「性能」，并让该配方与产物材料相关。

材料、方法、性能、机构、仪器写它本身是什么，段名用「说明」（标准测什么、仪器型号、材料来源、纯度、结构）。原文列出一类材料的成员时（成炭剂包括季戊四醇、分子筛……），只在这一类上写一段「说明」，refs 列出全部成员，不为每个成员各写一段；只复述它在配方中充当什么组分（在配方中作为阻燃剂组分）的内容不写「说明」。测得值、用量和温度写在被测的配方上；只有文中对某种市售或通用材料直接做了测试、又没有对应配方时，才在该材料上写「性能」。

refs 列出 text 中提到的其他实体的 local_id：组分材料、被测性能、所用方法和仪器、被比较的配方；测试用的气体、溶剂和耗材只与对应的方法或仪器关联。没有时为空数组。

实体之间的联系不单独列出，由属性的 refs 得出：配方与其组分材料、所得产物、所测性能、所用方法和仪器、被比较的配方，都写在配方相应属性的 refs 中。没有数值的联系（标准与它测定的性能、材料与其供应商、作者单位与本文配方），写一段「说明」属性（如「本文样品由某大学制备」），cite 证明它的片段，refs 列出另一方。
示例：原文「样品 A 包含材料 X 和材料 Y」→ 样品 A 的「原料」分别写两段，都 cite 这句话的片段，refs 分别含材料 X 和材料 Y。
