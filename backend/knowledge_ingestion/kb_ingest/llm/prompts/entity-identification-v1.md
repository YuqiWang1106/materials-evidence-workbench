你在为材料知识库列出一个窗口中的实体。
按下面的步骤做：
1. 读 source，找出其中出现的每个实体，给它一个本窗口内唯一的 local_id（如 m1、f1）。
2. 为每个实体选一个 type：
   - material：原料、助剂、填料、聚合物基体、牌号、化学名，以及作为讨论对象的材料类别（如膨胀型阻燃剂）。泛称（材料、样品、阻燃剂）只在指向具体物质时才列。
   - method：测试标准（GB/T 2406.2、UL-94）、制备方法（低温溶剂法、熔融共混）、表征和测试手段（锥形量热、X 射线衍射）。
   - property：被测量或被比较的性质（极限氧指数、溶解度、热释放速率峰值、拉伸强度、残炭率）。
   - organization：作者单位、公司、供应商。
   - instrument：仪器设备及型号。
   - formulation：一个被制备、并被测试或表征的具体样品：实施例、对比例、对照组、文中编号的样品，以及一次合成（按给定原料和条件制得某产物）。
3. 给 formulation 起名：
   - 用文中的样品名或编号（例如样品 A、实施例 3）。
   - 表格中每一列（或每一行）是一个样品时，为每个样品各列一个 formulation（实施例1、实施例2……）。
   - 一次合成没有编号时，名称写「产物 + 合成」。
   - 综述中引用的具体体系没有编号时，用原文词语组成在本篇唯一的简短名称。
   - 专利权利要求或发明内容中以范围给出的组成，列为一个 formulation，名称写「权利要求N组合物」（N 为所在权利要求的编号；只在发明内容中出现时写「发明组合物」）。
   - 单独的阻燃剂、添加剂、微胶囊列为 material；加入它们后被测试的复合材料才列为 formulation。示意图和通用工艺描述不列为 formulation。
   - 只为实际制备、给出了组成或结果的具体样品建 formulation；一类样品的泛称归到这些具体样品上。
4. 写 name 和 aliases：name 用规范全称，缩写和其他写法放进 aliases（「聚磷酸铵(APP)」→ name 聚磷酸铵，aliases ["APP"]）；没有别名时 aliases 为空数组。同一个概念只列一次（抗压强度与压缩强度、热释放速率峰值与 PHRR 是同一个 property）；更宽或更窄的概念分别列（热释放速率与热释放速率峰值）。property 的 name 写性质本身（缺口冲击强度、拉伸强度、热变形温度），单位、测试标准和测试方式写在配方的「性能」属性里，同一性质用不同标准或方式测得仍是同一个 property（Izod缺口冲击强度 → name 缺口冲击强度，aliases ["Izod缺口冲击强度"]）。
5. 对照 known_entities（本篇前面窗口已列出的实体）：同一个东西再次出现时，name 照抄 known_entities 中的写法。
6. 为每个实体给至少一处 mention：cite 是写有该实体名称的片段 id（只写编号本身，如 b12.3）。
entities 部分只列实体；用量、温度、测得值和结论写在 attributes 部分。
